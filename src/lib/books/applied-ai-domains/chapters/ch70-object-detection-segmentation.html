Chapters 68 and 69 covered classification: one label per image. That’s often not the question a real task actually asks. “Is there a defect in this frame” is classification. “Where exactly is the defect, and how big is it” is detection. “Which pixels belong to the defect” is segmentation. Whole-image classification throws away exactly the spatial information those questions need. This chapter covers architectures that keep it.

70.1 Motivation

Detection predicts a set of bounding boxes, each with a class label and a confidence score: “there’s a cat here,” with “here” being four numbers describing a rectangle. Segmentation goes further: a label for every individual pixel, producing a mask rather than a box: “these exact pixels are cat, these are background.” Both need the same underlying capability classification doesn’t: localised, spatially-resolved output, not a single whole-image summary. Worked Example 70 below trains both a simplified detector and a segmentation model, with every accuracy number measured directly.

70.2 Exposition

70.2.1 The R-CNN Lineage: From Slow-and-Accurate to Fast-and-Accurate

R-CNN (2014) proposed roughly 2,000 candidate regions per image via a separate, non-learned algorithm, then ran a full CNN forward pass independently on each cropped region. It worked, but running a whole CNN thousands of times per image is extremely slow. Fast R-CNN (2015) fixed the obvious inefficiency: run the CNN once on the whole image to get a feature map, then crop features, not pixels, for each proposed region from that single shared feature map, roughly 200x faster for the same accuracy, because the expensive part stopped being repeated per region. Faster R-CNN (2015) removed the last non-learned bottleneck: the region-proposal step itself becomes a small trainable network (the Region Proposal Network) sharing the same backbone features, rather than an external algorithm, end-to-end trainable, and faster again. Each step in this lineage is the same move repeated: find the part of the pipeline being redundantly recomputed or externally hand-designed, and fold it into the shared, learned, single-pass computation.

70.2.2 YOLO: A Different Philosophy

R-CNN-family detectors are two-stage: propose regions, then classify/refine them. YOLO (“You Only Look Once,” 2016) is single-shot: divide the image into a grid, and have the network predict, for every grid cell, in one forward pass, whether an object’s centre falls there, what its box is, and what class it is. No separate proposal stage. This trades some accuracy (particularly on small or heavily overlapping objects) for a dramatic speed advantage. Single-shot detectors are what real-time detection (video, robotics, Chapter 59) is generally built on. Worked Example 70’s detector implements a heavily simplified single-shot detector in exactly this spirit: a coarse grid, one predicted box per cell, trained end-to-end.

70.2.3 U-Net: Segmentation’s Answer

Producing a full-resolution, per-pixel mask from a CNN has a structural problem: the encoder downsamples repeatedly to build abstract, spatially coarse features, exactly what classification wants, and exactly what per-pixel prediction doesn’t, since fine spatial detail gets discarded along the way. U-Net (2015) solves this with an encoder-decoder structure: downsample (encoder), then upsample back to full resolution (decoder), and, critically, skip connections between each encoder resolution and the corresponding decoder resolution, concatenating the encoder’s fine-detail features directly into the decoder at the same spatial scale. This looks like ResNet’s skip connections but solves a different problem. Don’t conflate them. Chapter 69’s residual connections fix vanishing gradients in very deep networks; the two paths being added are at the same resolution, same purpose (letting a block default to identity). U-Net’s skip connections reinject spatial detail lost during downsampling. The two paths being concatenated are from different stages of the network (early, fine-detail encoder features and later, coarse-but-semantically-rich decoder features), and they’re concatenated (stacking channels), not added. Same word, same superficial “shortcut” shape, genuinely different job. Worked Example 70 measures exactly what removing U-Net’s skip connections costs.

70.3 Trade-offs and Limits

Two-stage detection (Faster R-CNN family) is generally more accurate, particularly for small/dense objects; single-shot detection (YOLO family) is generally faster, often by a wide enough margin to be the only option for real-time use. Choose based on whether latency budget or accuracy requirement is the binding constraint. Segmentation’s per-pixel output is inherently more expensive than detection’s per-box output. A mask has as many predictions as there are pixels, a box has four numbers, so segmentation is worth reaching for only when the task genuinely needs pixel-level precision (medical imaging, precise robotic grasping) rather than “where roughly is it.”

70.4 Procedures

Procedure 70.1 (Compute IoU for Boxes and Masks). When to use: evaluating any detection or segmentation prediction against ground truth. IoU is the standard overlap metric for both.

IoU thresholds in practice: IoU > 0.5 is a common “counts as a correct detection” threshold; stricter tasks (medical, precise robotics) often require 0.7+.

Procedure 70.2 (Implement Non-Max Suppression). When to use: a detector predicts multiple overlapping boxes for the same object; NMS keeps only the best one.

Common mistake: applying NMS across different classes together. Run it per class; a correctly detected cat and a correctly detected dog with overlapping boxes shouldn’t suppress each other.

Procedure 70.3 (Choose Two-Stage vs. Single-Shot Detection). When to use: selecting a detection architecture family for a new task.

70.5 Worked Example

A simplified single-shot detector (Exposition’s YOLO-style grid approach), trained end-to-end and evaluated on 300 held-out test images:

Metric Measured value
Mean IoU 0.878
Fraction with IoU > 0.5 1.000
Classification accuracy 1.000

Every one of the 300 test images cleared the IoU > 0.5 “correct detection” threshold from Procedure 70.1, and mean IoU (0.878) sits comfortably above even the stricter 0.7 threshold cited for precision-critical tasks, a strong result for a heavily simplified, single-box-per-cell detector on this task’s controlled complexity.

A U-Net segmentation model, trained twice, once with its skip connections intact, once with them removed (a plain encoder-decoder, everything else held identical), isolates exactly what those connections buy, directly rather than by assertion:

Configuration Dice IoU
With skip connections 0.9998 0.9997
Without skip connections (plain encoder-decoder) 0.9856 0.9719
Difference +0.0142 +0.0278

Both configurations perform well in absolute terms on this task, but the gap is real and directly attributable to the one architectural difference: skip connections improved Dice by 0.0142 and IoU by 0.0278. This is Exposition’s claim about why U-Net’s skip connections exist made measurable. Without them, the plain encoder-decoder has to reconstruct fine spatial boundaries purely from the coarse, downsampled bottleneck representation, and the measured mask quality is correspondingly (if modestly, on this task) worse. On tasks with finer detail requirements than this Worked Example’s, the gap between with-skips and without-skips would be expected to widen further, since the fine detail being reinjected matters more the more precise the required boundary.

70.9 Mental Model

Detection and segmentation are both “classification, but keep the spatial information classification throws away”: detection keeps it as a small number of boxes, segmentation keeps it at full pixel resolution. The R-CNN lineage is a story of removing redundant computation; YOLO is a story of trading a separate proposal stage for speed; U-Net is a story of explicitly routing fine spatial detail around the encoder’s necessary but detail-destroying downsampling. This chapter’s Worked Example turned that last story into a number: 0.0278 IoU, measured, not assumed, is what U-Net’s skip connections were worth on this task.
