Adam Algorithm (Simplified)

alpha, beta1, beta2, eps = 0.001, 0.9, 0.999, 1e-8
m, v = np.zeros_like(w), np.zeros_like(w)

for t in range(1, n_steps + 1):
    g = gradient(w)
    m = beta1 * m + (1 - beta1) * g
    v = beta2 * v + (1 - beta2) * g**2
    m_hat = m / (1 - beta1**t)
    v_hat = v / (1 - beta2**t)
    w = w - alpha * m_hat / (np.sqrt(v_hat) + eps)

API / Function Summary

scipy.stats.entropy(pk, qk=None, base=None, axis=0): returns entropy of pk, or KL(pk∥qk)\mathrm{KL}(pk \| qk)KL(pk∥qk) if qk is given. pk need not be pre-normalised. base=None gives nats; base=2 gives bits.

h = scipy.stats.entropy([0.5, 0.5], base=2)   # 1.0 bit
kl = scipy.stats.entropy(p, q, base=2)         # KL(p || q) in bits

log_loss, called as sklearn.metrics.log_loss(y_true, y_pred, labels=None, normalize=True), returns the cross-entropy (log) loss. y_pred is predicted probabilities, shape (n_samples,) or (n_samples, n_classes).

loss = log_loss(y_true, y_pred_proba)

sklearn.feature_selection.mutual_info_classif(X, y, discrete_features='auto', n_neighbors=3, random_state=None) (and mutual_info_regression for continuous targets): returns an ndarray of shape (n_features,), estimated mutual information with the target in nats, non-negative.

mi = mutual_info_classif(X, y, random_state=42)
