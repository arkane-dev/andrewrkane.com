Recurrent networks (LSTMs, GRUs) could process sequences, but carried two deep problems. They processed tokens one at a time, left to right, which made them impossible to parallelise during training. And long-range dependencies degraded. By token 100, information from token 1 was mostly gone. Transformers, introduced in “Attention Is All You Need” (Vaswani et al., 2017), solved both by abandoning recurrence entirely. Every token attends directly to every other token, in parallel. Training became dramatically faster. Long-range dependencies became trivial. The result is the general-purpose architecture behind everything from machine translation to code generation to modern chat models.

29.1 Motivation

The transformer’s key innovation is self-attention. Instead of processing a sequence step by step, every token asks “which other tokens in this sequence are most relevant to understanding me?” and weights their representations accordingly. In “The animal didn’t cross the street because it was too tired”, a human resolves “it” to “animal”, not “street”. Self-attention lets a model make this same connection directly, with the token “it” learning to attend strongly to “animal” and weakly to “street” based on patterns learned during training. Worked Example 29 below measures this exact resolution inside a real pretrained model, not as an illustrative claim.

29.2 Exposition

29.2.1 Self-Attention: The Mechanism

For each token, the model computes three vectors: Query (“what am I looking for?”), Key (“what do I contain?”), Value (“what should I contribute if attended to?”). The attention score between token iii and token jjj is score(i,j)=softmax(Qi⋅Kj/dk)\text{score}(i,j) = \text{softmax}(Q_i \cdot K_j / \sqrt{d_k})score(i,j)=softmax(Qi​⋅Kj​/dk​​), and token iii’s output is a weighted sum of all value vectors: outputi=∑jscore(i,j)⋅Vj\text{output}_i = \sum_j \text{score}(i,j) \cdot V_joutputi​=∑j​score(i,j)⋅Vj​. The dk\sqrt{d_k}dk​​ scaling (where dkd_kdk​ is the key dimension) prevents dot products from growing large enough to push softmax into a near-one-hot regime with vanishing gradients.

29.2.2 Multi-Head Attention and Positional Encoding

Rather than one set of Q/K/V projections, the transformer runs hhh sets in parallel (typically 8–12 heads), each free to learn a different relationship, subject-verb agreement, coreference, syntactic structure, with outputs concatenated and projected: MultiHead(Q,K,V)=Concat(head1,…,headh)⋅Wo\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) \cdot W_oMultiHead(Q,K,V)=Concat(head1​,…,headh​)⋅Wo​. Self-attention alone is order-invariant. “The cat sat” and “sat the cat” would score identically without it. So a positional encoding is added to each token embedding: a fixed sinusoidal pattern in the original paper, or learned position embeddings in most modern variants (BERT, GPT).

29.2.3 The Transformer Block and Architecture Variants

Each block chains two sublayers, each wrapped in a residual connection and layer normalisation: x → [Multi-Head Self-Attention] → Add & LayerNorm → [Feed-Forward] → Add & LayerNorm → output. The residual connection (x+sublayer(x)x + \text{sublayer}(x)x+sublayer(x)) gives gradients a shortcut path, which is what makes very deep transformer stacks trainable at all. Three architecture families follow from how these blocks are arranged. Encoder-only (BERT): bidirectional context, best for classification/NER/QA, can’t generate text. Decoder-only (GPT/Llama/Claude): causal masking, left-to-right generation, the architecture behind all modern chat models. Encoder-decoder (T5): encoder processes input, decoder generates output, suited to translation and summarisation.

29.2.4 Why Transformers Scale

Self-attention’s core operation, QKTQK^TQKT, is a matrix multiplication GPUs execute in parallel across all sequence positions simultaneously. An LSTM processing 1,000 tokens needs 1,000 sequential steps. A transformer processes all 1,000 at once. This parallelism is why scaling laws (Kaplan et al., 2020) hold. Performance improves predictably with more data, compute, and parameters, because the compute can actually be used efficiently. The cost is that attention has quadratic complexity in sequence length (O(n2)O(n^2)O(n2), since every token attends to every other). That’s why contexts beyond roughly 100K tokens need specialised techniques (sliding-window or linear-attention variants).

29.2.5 Estimating Model Size

For a decoder-only transformer, each layer’s parameters are dominated by four attention projection matrices (Wq,Wk,Wv,WoW_q, W_k, W_v, W_oWq​,Wk​,Wv​,Wo​, each dmodel×dmodeld_{\text{model}} \times d_{\text{model}}dmodel​×dmodel​) and two feed-forward matrices (dmodel×4dmodeld_{\text{model}} \times 4d_{\text{model}}dmodel​×4dmodel​ and back): N≈12⋅nlayers⋅dmodel2N \approx 12 \cdot n_{\text{layers}} \cdot d_{\text{model}}^2N≈12⋅nlayers​⋅dmodel2​ This ignores the embedding matrix (vocab_size×dmodel\text{vocab\_size} \times d_{\text{model}}vocab_size×dmodel​): small relative to total parameters for large models, non-trivial for small ones. Worked Example 29 checks this formula, embedding matrix included, against two real published models rather than treating it as an assumed rule of thumb. This single number, NNN, feeds two downstream questions covered elsewhere in this book: training cost (Chapter 33: FLOPs and optimiser memory scale with NNN and token count) and serving cost (Chapter 23: inference memory and latency scale with NNN and context length).

29.3 Trade-offs and Limits

Transformers win at any task involving text, classification, generation, extraction, QA, especially with long-range dependencies and a large pretraining budget to exploit. They lose at tabular data, where XGBoost (Chapter 12) still typically dominates. They lose at very small datasets, where classical models generalise better without the crutch of pretraining. And they lose at resource-constrained inference, where a BERT-scale model is 100–400MB against a logistic regression’s few kilobytes. True streaming or very-long-context use cases run into the quadratic attention cost directly. That’s why production long-context systems lean on retrieval (Chapter 31) rather than feeding everything into one attention pass.

29.5 Worked Example

Feed the classic coreference sentence, “The animal didn’t cross the street because it was too tired,” through a real pretrained DistilBERT (distilbert-base-uncased, 6 layers, 12 heads per layer, 66,362,880 total parameters). Read out attention scores from the token “it” to “animal” versus “street”, averaged across all 12 heads per layer:

Layer it → animal it → street
0 0.0364 0.0462
1 0.0456 0.0247
2 0.1012 0.0449
3 0.0297 0.0157
4 0.1688 0.0289
5 0.0666 0.0229

By layer 4, “it” attends nearly six times more strongly to “animal” than to “street” on average across heads. The single strongest individual head (layer 4, head 1) attends to “animal” with weight 0.513 versus 0.029 to “street”: a 17.8x ratio. This is Motivation’s coreference claim measured directly inside a real model’s weights, not asserted. A specific layer and head genuinely encode the “it” → “animal” resolution a human reader makes automatically. This model was never explicitly trained on coreference. The behaviour emerged from masked-language-model pretraining alone.

29.7 How This Connects

This chapter builds on Chapter 27’s tokenisation and embeddings (attention operates on token embeddings directly) and Chapter 28’s neural network foundations (attention is, mechanically, a specific kind of learned weighted sum, built from the same Linear/matmul primitives). It enables Chapter 30’s prompting, Chapter 31’s retrieval (which uses transformer encoders to produce the embeddings retrieval search runs over), Chapter 33’s pretraining, and Chapter 34’s fine-tuning: all four operate on the architecture defined here. It’s often confused with “LLM”. Every modern LLM is a transformer, but transformers are also used for non-language tasks (vision, protein folding, code). “LLM” names the scale and language focus, not the architecture.

29.9 Mental Model

Self-attention is a soft, learnable lookup table. For every token, it queries the rest of the sequence and aggregates information proportional to relevance. Stack many layers of this with feed-forward refinement between them, scale it up with more data and compute than intuition would suggest is necessary, and the result can write, reason, and converse. This chapter’s Worked Example is the reminder that this isn’t a metaphor. A real layer and head in a real pretrained model measurably encode “it” pointing to “animal,” found by looking, not by assuming the mental model is literally true.
